# Whitegram Languages v9 — AutoSafe

هذا الإصدار يحذف دائرة اللغات والقائمة المنسدلة بالكامل، ويجعل قسم **مميزات Whitegram** يتبع لغة Telegram تلقائياً.

## اختيار اللغة تلقائياً

الديلب يقرأ لغة Telegram الداخلية من المفتاح الذي تستخدمه نسخة Whitegram 12.8:

`wg_tgBaseLanguageCode`

واللغات المدعومة هي:

- العربية `ar`
- الإنجليزية `en`
- الإسبانية `es`
- الفارسية `fa`
- الفرنسية `fr`
- البرتغالية `pt`

مثلاً: عندما تكون لغة Telegram فرنسية تظهر مميزات Whitegram بالفرنسية، وعندما تكون عربية تظهر بالعربية. لا يوجد زر أو اختيار منفصل داخل Whitegram.

إذا كانت لغة Telegram غير واحدة من اللغات الست، يستخدم المشروع لغة التطبيق أو النظام إن كانت مدعومة، وإلا يرجع إلى الإنجليزية.

## معالجة كرش إعدادات Telegram الأصلية

أزيلت كل الاعتراضات العامة التي كانت تعمل على Telegram بالكامل:

- لا يوجد اعتراض عام على `UILabel` أو `UIButton`.
- لا يوجد اعتراض على `NSBundle`.
- لا يوجد اعتراض على `UIViewController` أو `viewDidAppear`.
- لا توجد دائرة أو نافذة إضافية أو مؤقت دائم.
- لا يجري تعديل أي نص داخل إعدادات Telegram الأصلية.

خارج Whitegram ينفذ الديلب فحصاً محدوداً للقراءة فقط على الصفحة الظاهرة. بعد التأكد من أنها الصفحة الرئيسية لمميزات Whitegram، يحفظ مسارها داخل الـNavigation Controller ويترجم الصفحة والأقسام التي تُفتح منها فقط. عند الرجوع إلى إعدادات Telegram ينتهي النطاق تلقائياً.

## البناء عبر GitHub Actions

1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل:
   `Build Whitegram Languages v9 AutoSafe`
4. نزّل Artifact باسم:
   `WhitegramLanguages-v9-AutoSafe`
5. الملف المطلوب للحقن هو:
   `WhitegramArabic.dylib`

## الحقن الصحيح

استخدم IPA أصلياً ونظيفاً من Whitegram 12.8 (55)، ثم احقن الديلب الجديد وحده وأعد توقيع التطبيق بالكامل.

لا تحقنه فوق نسخة تحتوي v4 أو v5 أو v6 أو v7 أو v8. تأكد أن:

`@rpath/WhitegramArabic.dylib`

مضاف مرة واحدة فقط إلى `LC_LOAD_DYLIB`.

## التغطية

كل لغة مترجمة تغطي 742 نصاً من نصوص Whitegram، مع فحص تلقائي للمتغيرات مثل `%@` و`%d` قبل البناء.
